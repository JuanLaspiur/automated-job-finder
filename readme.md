# 🤖 JobHunterBot

**Automatización de búsqueda de empleo con Puppeteer + Node.js**

JobHunterBot es un proyecto en evolución que nace como un script automatizado para buscar ofertas laborales en LinkedIn usando Puppeteer. Su propósito es convertirse en un backend sólido y escalable para automatizar la búsqueda de empleo en múltiples plataformas como LinkedIn, Indeed, Computrabajo, y más.

---

## 📌 Características actuales

- Inicia sesión automáticamente en LinkedIn
- Realiza búsquedas de empleo con criterios personalizados (ej. "Desarrollador React")
- Extrae y muestra resultados relevantes
- Simula un navegador real para evitar bloqueos

---

## 🚧 Próximamente

Este proyecto crecerá hasta convertirse en una API REST robusta con:

- Autenticación de usuarios
- Gestión de perfiles y preferencias de búsqueda
- Soporte para múltiples plataformas (Indeed, InfoJobs, etc.)
- Programación automática de búsquedas
- Notificaciones de nuevas ofertas por correo o Telegram

---

## 🛠️ Tecnologías

- [Node.js](https://nodejs.org/)
- [Puppeteer](https://pptr.dev/)
- [dotenv](https://www.npmjs.com/package/dotenv) para variables de entorno
- Brave (como navegador automatizado)
